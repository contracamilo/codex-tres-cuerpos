# Instrucciones de la demo

- Python 3.11 o superior, solo biblioteca estándar.
- Mensajes y documentación en español.
- Sigue docs/PROBLEMA.md y conserva las condiciones iniciales citadas.
- Ejecuta `python3 -m unittest discover -s tests -v`.
- Comprueba conservación física y convergencia, no solo que el programa ejecuta.
- No presentes una simulación como una solución analítica general.
- Deja la PR abierta para revisión durante la charla.
